# English Test — Word Quiz（网页版）

完全离线的英语背单词应用，**单文件 HTML**，内置 **3682 个单词、7237 条中文释义**。用浏览器直接打开即可使用，无需联网、无需安装。

## 功能

- 每轮 100 题，从 3682 词随机抽取
- 三种模式：中译英 / 英译中 / 混合模式
- 两个独立错题本（中译英 / 英译中），可温习错题
- 单词朗读发音（TTS）
- 进度条、正确率圆环、错题回顾
- 响应式布局，适配手机和桌面

## 使用方式

直接用浏览器打开 `index.html` 即可。

## 部署到 GitHub Pages

本仓库根目录即为 `index.html`，可直接在仓库设置中开启 GitHub Pages（Settings → Pages → Deploy from a branch），即可获得在线访问地址。

## 说明

本文件与桌面版仓库（`english-test-desktop`）中的 `index.html` 内容完全一致，本仓库为纯网页形态，可单独部署。
